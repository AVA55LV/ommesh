# Мост для радиостанций MeshCore с BLE

Компьютер с Bluetooth Low Energy подключается к радиостанции, а Nokia 700 обращается к компьютеру по Wi-Fi. Интернет для обмена сообщениями не нужен. Компьютер и Nokia должны находиться в одной локальной сети с разрешёнными соединениями между устройствами.

## Установка и подключение

1. Установите Python 3.11 или новее. Откройте терминал в каталоге `bridge` и выполните команды.

   ```sh
   python3 -m venv .venv
   . .venv/bin/activate
   python -m pip install -r requirements.txt
   python ble_bridge.py --scan
   ```

   В Linux нужен работающий BlueZ. Если в графической среде нет запроса PIN, оставьте `bluetoothctl` открытым в отдельном терминале, включите `agent KeyboardDisplay` и выполните `default-agent`. В macOS разрешите терминалу доступ к Bluetooth в настройках конфиденциальности.

2. Скопируйте идентификатор своего радио из списка. Узнайте IPv4-адрес компьютера в настройках сети. В команде ниже вместо примера `192.168.1.20` укажите этот адрес. Если радио уже подключено к другому клиенту, завершите там сеанс.

   ```sh
   python ble_bridge.py --device "<идентификатор из --scan>" --listen 192.168.1.20
   ```

   При первом сопряжении введите PIN с экрана радио. Для некоторых моделей без экрана заводской PIN — `123456`. Дождитесь сообщения «Радио готово». На macOS запрос PIN может появиться при первой попытке подключиться с телефона. После ввода PIN повторите подключение на Nokia, если она уже показала ошибку.

3. Откройте OMMesh Belle, введите IPv4-адрес компьютера и порт `5000`. Если на компьютере включён брандмауэр, разрешите вход на этот порт из локальной сети. Для другого порта укажите `--port` при запуске моста и тот же порт на Nokia.

4. Оставьте мост запущенным на время работы. После разрыва связи он подключается к радио заново. Чтобы остановить мост, нажмите `Ctrl+C`.

TCP-соединение моста открыто для одного клиента и не использует шифрование или пароль. Подключайте его в доверенной локальной сети и не открывайте порт в интернете. По умолчанию мост слушает `127.0.0.1`. Для подключения с Nokia нужен параметр `--listen` с адресом компьютера.

Описание формата обмена. [MeshCore Companion Protocol](https://github.com/meshcore-dev/MeshCore/wiki/Companion-Protocol)

Направления GATT и UUID. [Прошивка MeshCore](https://github.com/meshcore-dev/MeshCore/blob/75b04ef06def54b348400cb1b138afb6749ffd4f/src/helpers/esp32/SerialBLEInterface.cpp)
